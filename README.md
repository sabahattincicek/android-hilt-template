## First-Time Setup

If you are using this template for the first time, **follow the instructions in [`SETUP.md`](SETUP.md) before starting development**.

The setup guide covers package renaming, Gradle configuration, project name, application name, the AI assistant files (`AGENTS.md`, `DEVLOG.md`, `ROADMAP.md`), and the required cleanup steps.

> **Do not skip the setup steps.**
